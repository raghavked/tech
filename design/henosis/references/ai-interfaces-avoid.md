# AI interfaces to avoid: the 2026 sameness, and ten elements for Henosis

## What the best work does

**It names the template and refuses it.** ChatGPT, Claude, Gemini, Perplexity, Copilot: sidebar left, centred input at the bottom, alternating messages in the middle, suggestion chips. Hoang Nguyen counts twelve near-identical platforms and calls it "design abdication" ([UX Collective](https://uxdesign.cc/are-we-designing-ai-products-all-wrong-d54d1005c92f)). Adi Leviim is sharper: chat is not a paradigm, it is what shipped fastest in 2022 and calcified; the empty state collapsed into "a centred text field, a placeholder string, and four to six suggested prompts" ([what shipped](https://uxdesign.cc/the-chat-box-isnt-a-ui-paradigm-it-s-what-shipped-96e931d92769); [death of the empty state](https://uxdesign.cc/the-death-of-the-empty-state-in-ai-products-2026-e11439fbb688)). Irvan Lathief's test is the one to keep: *the AI cannot show a chat box; what does the product become?* The artifact becomes the interface; chat drops to a fallback ([Chat is not the interface](https://www.irvanlathief.com/sol/chat-is-not-the-interface)).

**It gives the blank field affordances.** Amelia Wattenberger's 2023 argument anchors every later essay: a text input "looks the same as a Google search box, a login form, and a credit card field," so every user carries the burden of learning what works. Her answer is controls baked into the interface (sliders for audience and depth, suggestions in the margin) rather than prose the user must invent ([wattenberger.com](https://wattenberger.com/thoughts/boo-chatbots/)). Kosta Canatselis restates it for 2026: chat stays for the open-ended 9pm question; every specific action gets its own button, form or artifact ([Stop putting a chat box on everything](https://world.hey.com/kostac/stop-putting-a-chat-box-on-everything-501a16e5)). Zurb's Radar adds the copy half: one term per concept, a written failure state, because "a blank box says nothing" ([Radar](https://radar.zurb.com/article/chat-box-is-the-lazy-choice-what-sharper-ai-teams-build-instead)). Leviim's four properties for an empty state: a worked example, a starting verb, exposed limits, action before speech.

**It drops the sparkle and the purple.** NN/g found not one participant read the sparkles icon as "AI"; it was guessed as deals, favourites, effects, a plus sign ([Kate Kaplan, NN/g](https://www.nngroup.com/articles/ai-sparkles-icon-problem/)). Josh Clark's verdict: sparkles now mean "this feature is weird and probably broken," and the right symbol for a machine-intelligent feature is no symbol at all, the way spell-check gets no badge ([Your Sparkles Are Fizzling](https://bigmedium.com/ideas/your-sparkles-are-fizzling.html)). The purple gradient (Gemini, Copilot, OpenAI decks) borrows the colour of magic and hidden power, exactly what people fear in a black box; it only works "balanced with something human: a light background, simple language, warmth" ([Indie Hackers](https://www.indiehackers.com/post/the-ai-purple-problem-why-every-ai-brand-looks-the-same-6cb0aa2a02)). Propellant names Claude's beige-and-terracotta serif warmth and Twelve Labs' cinema-editorial identity as the two brands that escaped the monochrome chat box ([Monochrome to Technicolor](https://www.propellant.co.uk/post/monochrome-to-technicolor-the-maturing-of-ai-design)). Henosis lives in that warm camp; the risk is the next cliché set (italic accent words, "01 / 02 / 03" eyebrows, pill buttons), now on Anthropic's own ban list ([Figmalion](https://figmalion.com/topics/claude)).

**It treats the agent as a colleague with a shape, a place and a record.** Atlassian's AMP reserves the hexagon for agents so circles stay human, leads every attribution with the agent and tucks the invoking person behind at a 2px offset, puts agents in presence piles, telepointers and view counts, and never hides CLI or MCP agents ([Atlassian AMP](https://atlassian.design/amp)). The CHI 2026 prototype *multi* found teams fold agents into existing norms of authorship when agent replies arrive as ordinary comments and tasks are shared objects ([ACM](https://dl.acm.org/doi/full/10.1145/3772318.3790648); [multieditor.net](https://multieditor.net/)). MagicPath renders every agent as a named orb on the canvas with "no separate 'agent is thinking' sidebar" ([MagicPath](https://www.magicpath.ai/documentation/collaboration/live-multiplayer)); Nimbus codifies ghost cursors, context-selection rings, draft overlays and a staging drawer so four agents cannot drown three people ([Nimbus](https://gonimbus.ai/blog/the-shared-canvas-for-human-ai-teams/)); tldraw puts a drawable canvas inside the conversation ([tldraw](https://tldraw.dev/blog/text-is-not-enough)). And the AI product designers call *fun* is a terminal: Claude Code's three text tones, flavour-text verbs, counters and RPG-style numbered choices feel "responsive and alive" without one bubble ([Calvin French-Owen](https://calvinfo.substack.com/p/the-coding-agent-metagame)). Matt Jedraszczyk's line is the brief: when we collaborate in Figma "we don't see a chat; we see avatars, comments, screenshots" ([Thinking past the cliché](https://uxdesign.cc/thinking-past-the-cliche-of-llms-ai-design-patterns-c9b849fce9e8)).

## Ten elements for Henosis

1. **Ledger column, not bubbles.** One flush-left text column on cream, `display: grid; grid-template-columns: 56px minmax(0, 68ch)`, author mark in the gutter, no backgrounds behind words. Session stream, groups and chats. People and agents write into the same typographic column; who spoke is marginalia, not a coloured balloon.

2. **Composer as a bottom rule.** Full-width `textarea` with `field-sizing: content` and `border-top: 1px solid rgb(86 53 45 / .12)`, aligned to the ledger's text edge, never a centred floating pill. Session and chats. One line addresses a person, an agent or the whole room.

3. **Addressing prefix chips.** A `To:` row of `inline-flex` chips (Fraunces 14 for the name, 6px dot in Dress Blues for a person, Apricot for an agent) that `@` populates; `aria-live` announces the audience. Composer, groups. Addressing is one gesture; the Agent/Team toggle becomes visible recipients.

4. **Verb shelf, not "ask anything".** The new-session empty state is four verbs (`Plan`, `Review`, `Release`, `Ask`) in a `grid-auto-flow: column` row above one worked example rendered from a real past session, with the room's limits printed under it. Onboarding, new session. The room shows what it can do and what it cannot, the way a good tool shows its edges.

5. **Ring meter.** The mark as the only progress indicator: two SVG `<path pathLength="100">` arcs with `stroke-dashoffset` driven by `--human-done` and `--agent-done`; the centre dot appears at 100/100. Plan card, release gate. Progress is literally the two arcs closing into one ring.

6. **No sparkles, no AI badge.** Agent actions carry a verb in Inter 500 and the agent's name in Fraunces; icons are 1.5px-stroke glyphs only, with a lint rejecting `sparkle`, `wand`, `magic` and any hue in the 270 to 300 degree band. Every screen. Agent work is a feature, not a trick; nothing is segregated as "AI".

7. **Tool steps as a mono commit log.** Each tool call is one 12px monospace line, `font-variant-numeric: tabular-nums`, a left tick, expanded with `<details>` and `interpolate-size: allow-keywords` for a height transition. Session stream, Details drawer. The agent's work reads like a colleague's commit history: pop the hood anywhere.

8. **Agent-leads attribution pair.** For an action taken on someone's behalf, the agent avatar (hexagon, `clip-path: polygon(...)`) leads and the person's circle sits behind at `translate: 2px 2px`, `z-index: -1`. Approvals, history, project page, manager overview. One glyph pair shows the whole accountability chain.

9. **Margin notes, not a second chat.** Agent commentary on a document or plan is a sidenote anchored to its passage with CSS anchor positioning (`anchor-name: --p12; position-anchor: --p12; inset-inline-start: anchor(right)`), hairline connector, resolve and reply inline. Details drawer, plan card, project page. Agents review in the margin like any reviewer; no parallel conversation to reconcile.

10. **Artifact-first split.** Desktop layout `grid-template-columns: minmax(360px, 2fr) 1px 3fr`: ledger left, artifact (plan, diff, doc, board) right, a draggable hairline between. Desktop, project page. The work is the interface; the conversation is the column beside it, and both belong to everyone.
