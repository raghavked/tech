# Editorial type in software: what the best work does, and ten elements for Henosis

## What the best work does

**It uses the optical-size axis instead of faking sizes.** Fraunces ships four axes (wght, opsz, SOFT, WONK). Below 18px the optical-size axis opens letterspacing, raises the x-height, drops contrast and swaps the "wonky" leaning h/n/m out automatically; browsers do this for free when `font-optical-sizing: auto` is on ([Fraunces minisite](https://fraunces.undercase.xyz/); [Undercase](https://undercase.xyz/fonts/fraunces)). Inter 4 did the same from the sans side: six "Display" designs on an opsz axis from 14 to 32, text cuts with tall x-height and ink traps, display cuts with cleaner curves ([rsms.me/inter](https://rsms.me/inter/); [Inter 4.0 release](https://github.com/rsms/inter/releases/tag/v4.0)). The lesson is that one variable file can carry both a 12px label and a 64px masthead if you let the axis move.

**Display serif over neutral sans is the working pairing.** The Browser Company sets Marlin (a sharp serif) and Marlin Soft for headlines at 46px with -0.04em tracking, Inter Variable for everything inside the product mockups, and a tracked mono (ABC Favorit Mono, 12px, 0.15em) for micro-labels so metadata reads as a third register ([Refero, Arc](https://styles.refero.design/style/ca93daf1-daf3-41b7-8248-8f63082761e8)). Instrument built Instrument Serif deliberately to "truly contrast Instrument Sans" while sharing anatomy; it is a condensed display face meant for large sizes, and designers who ship it say 48px minimum ([GitHub, instrument-serif](https://github.com/instrument/instrument-serif); [Instrument rebrand](https://www.instrument.com/latest/from-old-to-bold-instrument-rebrand-signals-energetic-shift); [Type Righter](https://bockenstette.com/workshop/type-righter)). Anthropic's Claude app pairs Tiempos for the assistant's prose with Styrene for chrome and user messages ([type.today](https://type.today/en/journal/anthropic)), a typographic role asymmetry worth noting because Henosis should invert it.

**Restraint reads as confidence.** Stripe Press uses one serif superfamily, Ivar, for everything including buttons: reading text at 25px on a 1.5 line-height, labels at 600 with +0.32px tracking, square corners, no sans anywhere ([Tastekit, Stripe Press](https://tastekit.dev/gallery/apps/stripe-press)). Are.na commissioned Areal from Dinamo, a redrawn Arial, and sets h1, h2 and body all at 19px/1.45, with hierarchy from weight only and list markers hung into the margin ([Are.na Editorial](https://www.are.na/editorial/introducing-areal-are-nas-new-typeface); [PageProofer, Are.na](https://pageproofer.com/inspiration/warm-editorial/arena/)). Figma Config 2025 runs a single weight of Figma Sans at 80px/0.95 on black, hierarchy from scale alone, with the condensed cut for display ([Figma blog](https://www.figma.com/blog/how-we-shaped-the-visual-identity-for-config-2025/); [Refero, Config](https://styles.refero.design/style/8caa5004-a8cc-4c7e-a2bb-00ff60618729)). Readymag's display face is only allowed at 30px and above, tracked -0.067em at 80px, with Graphik below ([Refero, Readymag](https://styles.refero.design/style/1287abc9-da90-410d-a997-96b8b11ad646)).

**Measure and rhythm are set, not inherited.** 45 to 75 characters per line, 66 ideal; width in `ch` or `em` keeps the measure stable when the reader resizes ([webtypography.net 2.1.2](https://webtypography.net/2.1.2); [Butterick, line length](https://practicaltypography.com/line-length.html)). Line spacing 120 to 145% for body; Butterick starts his web grids from `1rem` rather than a rigid baseline grid ([Butterick, grids](https://practicaltypography.com/grids.html)).

**Numerals are a feature, not an afterthought.** `font-variant-numeric: tabular-nums slashed-zero` maps to OpenType `tnum` and `zero` ([MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-variant-numeric)). Inter adds `ss01` open digits and `ss02` disambiguation; Blender froze `ss01`, `ss02` and `tnum` into its UI build of Inter to stop numbers "jiggling" ([Blender PR 112795](https://projects.blender.org/blender/blender/pulls/112795)). Söhne, the grotesk inside many premium products, ships tabular numerals, slashed zero and a Mono cut designed "in deference to contemporary typography" ([Klim, Söhne design information](https://klim.co.nz/blog/soehne-design-information/); [Klim, Söhne](https://klim.co.nz/fonts/soehne/)).

## Ten elements for Henosis

1. **Session masthead on the axis.** `h1{font:500 clamp(2rem,4vw,3.5rem)/1.05 Fraunces; font-optical-sizing:auto; font-variation-settings:"SOFT" 50,"WONK" 0; letter-spacing:-0.02em}`. Screen: session header. One serif headline names the work; it belongs to the room, not to a person or an agent.

2. **One voice, two arcs.** Every turn uses the same `font:400 1rem/1.5 Inter` in Chocolate Fondant; authorship is a 20px inline SVG ring before the name, left arc `fill` for people, right arc `stroke` for agents, both arcs when the turn was co-authored. Screen: session transcript. Unlike the serif-for-AI, sans-for-human convention, nobody gets a different typeface.

3. **The 66ch column.** `.stream{max-width:66ch; margin-inline:auto}` with `padding-inline:16px`. Screen: transcript and recap. Human prose and agent prose sit on the same measure, so neither reads as a sidebar to the other.

4. **Rhythm from one line.** `:root{--lh:1.5rem} .turn{line-height:var(--lh); padding-block:var(--lh)} .avatar{block-size:var(--lh)}`. Screen: transcript. Turns land on a shared beat whoever wrote them; a 400ms agent reply and a 4-minute human reply occupy the same grid.

5. **Decision pull-quotes.** `.decision{font:italic 400 1.375rem/1.3 Fraunces; font-variation-settings:"opsz" 22,"SOFT" 100; border-inline-start:2px solid #E2C4A6; padding-inline-start:1.25rem}`. Screen: transcript and recap. Decisions get the editorial register regardless of who proposed them; the attribution line below carries the two-arc mark.

6. **Ledger numerals.** `.ledger{font-variant-numeric:tabular-nums slashed-zero; font-feature-settings:"ss01"; text-align:end}`. Screen: session ledger (tokens, cost, durations, tool calls). People's hours and agents' tokens align on the same decimal, same width.

7. **Tracked mono eyebrows.** `.eyebrow{font:500 11px/1 ui-monospace,"Geist Mono",monospace; letter-spacing:.12em; text-transform:uppercase; color:#2A3244}`. Screen: roster and tool cards. Role tags "PERSON", "AGENT", "TOOL" share one voice and weight, so the roster reads as a cast list.

8. **Optical handoff in Inter.** `.title{font-size:1.375rem; font-optical-sizing:auto}` plus `.label{font-variation-settings:"opsz" 14}`. Screen: everywhere Inter appears above 20px (card titles, roster names). The display cut appears only by size, never by author.

9. **Breathing weight as presence.** `@keyframes breathe{to{font-variation-settings:"wght" 560}} .name[data-active]{animation:breathe 1.2s ease-in-out infinite alternate}`, guarded by `prefers-reduced-motion`. Screen: roster. A person typing and an agent working show the same quiet weight shift.

10. **Hung markers in the recap.** `.recap ol{list-style:none} .recap li::before{content:counter(step) "."; position:absolute; inset-inline-start:-2.2ch; font:500 1rem Fraunces; color:#56352D}` with `hanging-punctuation:first`. Screen: session recap. Steps hang in the margin like Are.na's definition list, numbering contributions by the ring, not by who did them.
