6
1
A skip link first

"Skip to the session" lands on the stream. The rail keeps its links, but a keyboard user no longer pays for them on every page.

7–11
Stars take one stop, not five

Each star is a button today. Make the five a radiogroup with roving tabindex: Tab lands on the current value, arrows change it, Space confirms.

7
Details takes focus and gives it back

Opening the drawer moves focus to its heading, Escape closes it and returns focus to the button. The rail's Share sheet gets the same.

6
The composer is reachable by key

Keep it last in the DOM, but give it / as a shortcut and announce it in the shortcuts sheet. The Agent/Team toggle becomes one stop with arrow keys.

8
Rail after the stream for readers

Order the DOM main first, rail second; the visual layout stays. Rail cards stay links with one stop each, numbered after the composer.

05

Fixes proposed, in order

Six blocking fixes land in tokens and one component; the rest are markup. Nothing here changes how a screen looks to a sighted teammate at a glance, except the stars and the focus ring, which get sharper on purpose.

P0

Darken ink-3 and warn in both themes

tokens.css

Lifts timestamps, estimates, the budget label and drawer headings to AA. Dark gets the green and red fixed too.

--ink-3: #6A7183;   --warn: #946021;
/* dark */ --ink-3: #9CA3B2; --warn: #D8A05A;
           --ok: #7DB577;    --danger: #D77A6D;
P0

Focus is a ring, not a glow

tokens.css

The app's tokens already carry --focus-ring; the design tokens still ship the glow. Align them.

:focus-visible { outline: 2px solid var(--accent);
  outline-offset: 2px; box-shadow: 0 0 0 5px var(--apricot-soft); }
P0

Stars as one radio group

ui.tsx · Stars

Five buttons become five radios with roving tabindex. One tab stop, arrows to choose, and the group names itself "Your rating".

<div role="radiogroup" aria-label="Your rating">
  <button role="radio" aria-checked tabindex="0|-1"
    aria-label="3 of 5 stars">
P0

State in words next to every colour

ui.tsx · Status, TeamPill, TokenMeter

Hidden text for the dot, a sentence for the pill, role="meter" for the budget bar with a value text in tokens.

<span class="status running"><span class="sr">running</span>…
<div role="meter" aria-valuenow="82"
  aria-valuetext="12.4k of 15k tokens, 82%, amber">
P0

Approvals and gates announce once

SessionView, Approvals

Feed the existing polite toasts region one sentence when a notice arrives, written in the product voice. Never re-announce on re-render.

Release gate: Bo's agent asks to run stripe
prorations --apply. Needs two ratings at 4+.
P0

The check draws without motion

tokens.css

Under the reduce rule and calm mode, put the stroke at its end state so a granted approval still shows its mark.

@media (prefers-reduced-motion: reduce) {
  .draw { stroke-dashoffset: 0; } }
:root[data-motion="calm"] .draw { stroke-dashoffset: 0; }
P1

Skip link, drawer focus, composer key

App shell

"Skip to the session" first in the DOM; Details and Share move focus in and return it; / focuses the composer and is listed in the shortcuts sheet.

P1

Names that teammates would say

AgentCard, Avatar stack, Send

Compose one label per rail card; one sentence per presence stack; the send button named after the toggle; the mark hidden wherever it is decoration.

P1

Loaders rest with a word

Loader

Orbit and weave fall back to a single dot or bar beside "Joining…" or "Reconnecting…", which the Loader's existing role="status" label already reads.

P1

Toasts wait under reduced motion

Toasts

With no rise to catch the eye, a toast holds for at least 8s and gains a Dismiss. Approvals never live only in a toast.
