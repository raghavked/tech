Motion on this page

Motion means joining or living.

Every animation in Henosis, with its duration, easing, trigger and what Calm mode does to it. Every demo is live; the toggle above shows the sheet as the Payments team sees it with Calm on. Nothing on this sheet moves for decoration.

Three clocks120 ms for a press, 200 ms for a hover, 320 ms for something arriving. Loops run 1.4–1.8 s.
Rest is the end stateWithout motion an element sits where it ends. No animation ever hides a thing until it plays.
Opacity, transform, strokeNothing animates layout. Colour crosses only on the Team pill and a team's accent.
Calm turns it all offprefers-reduced-motion or the team's Motion setting. Same markup, no script.

04

A join, in order

What plays, and when, in the 1.9 s after Ana opens Billing page · Checkout. Everything is timed from the join event in the fold.

Timeline · "Ana joins the circle."

Ana joins the circle.From the invite link · 4 here · Bo has the baton
BoCyDAn

The join is a line in the stream, not a modal. The line rises first; the mark settles once at 40 px while the dot lands; Ana's avatar ripples into the stack as the dot lands; the needs-you badge and the status dot pick up after that. Nothing overlaps the mark's swing except its own line.

An agent joining reuses the same line with the agent's name in the hand colour and its crew: Dee's agent joins the circle. Invoice rollout · Solo

Leaving is a quiet divider with no motion. The ring does not open again.

What Calm keeps

  • Colour and state. The running dot is still green, the Team pill still apricot, the check still drawn. Only the change is instant.
  • The focus ring and hover backgrounds, because those are feedback, not motion. They appear without their 120–200 ms ease.
  • Loaders at their finished frame: closed ring, dots stacked as one, a plain strand, flat lines. Copy carries the wait: "1,204 of 2,310 events folded."
  • Toasts and notices still arrive and leave on the same clock, just without the rise.

How it is decided

/* tokens.css: every animation sits under one guard */
@media (prefers-reduced-motion: no-preference) {
  :root:not([data-motion="calm"]) .toast { animation: toast-up var(--t-slow) var(--ease-arrive) both; }
  …
}
/* theme.ts: the team's Motion setting sets the attribute */
if (theme.motion === "calm") root.dataset.motion = "calm";
/* components that time something to an animation ask */
const motion = useMotion(); // "full" | "calm"
