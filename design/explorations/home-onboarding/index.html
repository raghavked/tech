First run on the desktop

Three screens between opening the app and watching an agent: who you are, which team, which session. Each is the same empty window with one narrow column in it, and the third is the product itself with the sidebar arriving for the first time. There is no tour, no checklist, no welcome card. Signing in asks for one address; choosing a team is two rows; the home of a project is the list of what is live plus the composer, which is also how a session is created. The one accent moves from the Continue button to the send arrow and stays there.

1Sign in

The window opens empty. One field, one button, two quieter ways in. The copy says what will happen and what will not: a code is sent, there is no password. The mark sits above the title as the only picture on the screen.
