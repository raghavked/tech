# Session list states: rationale

**Decision.** A session row stays a row: one six-pixel status dot on the left, a title, and at most one mark on the right. Status is the dot's colour (amber waiting, red blocked, green running, grey paused, faded done, hollow idle, none archived) and, where there is room, a word. Unread is typographic: the title goes to weight 500 and a five-pixel ink dot sits on the right. "Needs you" is the word *you* in the same slot, and it outranks the unread dot. A pause ordered by project direction is the only dot that changes shape, to two small bars in the same grey, because the thing that matters is who can undo it, not that it is louder. The project page uses the identical system with a gutter dot for unread, the status word on the right, and a second line in the agent's grammar that names the direction or the contention.

**Rejected.** Unread counts and badges: a session is a conversation, not an inbox. Coloured pills for status. An accent-coloured needs-you marker, which would spend the one accent on a list. A separate "Needs you" section in the sidebar; the section line says "2 need you" instead. A distinct colour for directive pauses.

**Carry forward.** The dot-colour and right-slot precedence rules; the pause glyph for directives; needs-you only for drivers and the lead; recency sorting with the count in the section line.
