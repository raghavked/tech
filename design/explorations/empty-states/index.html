Nothing here yet

Five places a reader can land and find nothing: a project with no sessions, a team with no projects, a memory with no entries, an inbox with nothing addressed to them, and the app with no connection. Each is drawn in the same shell as everything else, with the title the page would have anyway, one sentence that says what will fill it, and one action that starts filling it. No illustrations, no tour, no tips. The sentence does the explaining; the action is the only strong colour on the screen.

The grammar

TitleThe title the page would have anyway, in the serif. An empty page is still that page.
One sentenceSays what is missing, then what fills it, joined by a semicolon. Secondary ink, never bold, never a heading.
One actionThe thing that fills it: the composer, a primary button, or a link onward. It carries the only strong colour on the screen.
Sidebar echoThe sidebar says the same thing in three italic serif words under the section, so the empty state is visible before the page is opened.
Offline is a noticeNot a page. The status word by your name turns, the notice sits where the next event would, the send arrow goes to ink.
