Replay scrubber

Everything in a session is an event in a replayable log, so any turn can be shown exactly as it was. This is the control for that: a thin line under the top row, one dot per turn, a native range input as the handle. Drag it back and the column folds the log up to that turn; a label says where you are, and one button brings you back to now. Below: the strip at rest, the strip while viewing turn 9 of 14, the anatomy, and the same strip at phone width.

1At rest, on now

The strip is always there, 24 px tall, under the top row. Dots in tertiary grey, the handle on the last turn; the label is the one faint line and the composer keeps the only accent. Hovering a dot peeks at what happened in that turn.

3Anatomy

What the strip is made of, so it can be built once.

The line1 px, the hairline token

Runs the width of the main pane inside the 16 px gutters. It is the only horizontal rule above the column; the top row has none.

The dotsone per agent turn
5 px, tertiary grey: a turn that is at or before the handle.
Hollow: a turn ahead of the handle, not yet folded in.
7 px, text colour: a turn with a decision in it (an approval settled, a contention resolved, a handoff). Hollow when ahead.

Turns are spaced evenly, not by clock time, because a long silence is not a long turn. Past 60 turns the dots thin to a plain line and the handle still snaps to turns.

The handlea native range input

14 px, text colour, a 3 px ring in the page colour so it sits on the line. <input type="range" min="1" max="14" step="1"> with the track made transparent; the dots are a decoration behind it. Keyboard and screen readers get the input for free, with aria-valuetext set to "turn 9 of 14, 14:02".

Keys
← → one turn · Home End first and now · Esc return to now
Drag
The column re-folds live while dragging; nothing is fetched, the log is already local.
Scroll
Scrolling the column above its top while on now does not enter the past. Only the strip does.
The labelone line, 13 px

On now: the count, the start time, who was in. In the past: Viewing turn 9 of 14 · the clock time · a few words on what came next, so nobody is lost. The buttons sit at the right end of the same line: Fork from here as a ghost, Return to now as the primary. The send arrow is gone from the composer while viewing the past, so the screen still has one accent.

What changes belowthe column and the composer

The column is the log folded up to that turn: notices show the state they had then, tool lines stay, later events are not rendered. The last row is a divider naming what lies ahead. The composer stays in place so the layout does not jump, but its text explains the state and the accent leaves it. The top row says "Viewing the past" as a status word with a dot, and the apricot crease drops under the strip.

4At phone width

Mobile is secondary, but the same strip works at 390 px: smaller dots, the label wraps to two lines, the buttons keep their place.
