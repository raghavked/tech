# Command palette: rationale

**Decision.** ⌘K is one field over one list. Empty, the list is the verbs of the session in view (steer, approve, hand off, fork, fold), then "Go to" and "Recent". Typed, the same list answers from three places: the words offered back as a directive, the sessions in the project, and team memory with the open contention first and attribution ("Ana · billing-42 · 9f3c1a") on every line. A row is a 16px line icon, a verb or a name, and grey context on the right; state is a word with a dot ("needs you · 1 of 2 drivers · cannot be undone"). Selection is the two-pixel apricot bar the sidebar already uses; matches are underlined in apricot, not highlighted. The palette carries no accent, and the send arrow beneath it drops to ink while it is open, so the screen still has at most one strong colour.

**Rejected.** Tabs or filter chips inside the palette (chrome; the groups do the sorting). Keyboard shortcuts on every row (noise against the context words; the legend lives in the footer). A red row for the irreversible approve (a second colour that teaches skimming). A separate search box for memory (one field is the point).

**Carry forward.** Any text is a steer. Groups as words with a count. Verb first, consequence in words. Attribution on every memory line, and the contention always above the entries it disputes.
