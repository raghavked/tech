Handing off the seat

The driver is a token one human holds. Handing it off is an offer, a brief, and an answer. The offer and the reply are quiet notices in the stream like any other ask; the brief is computed from the log, so it is shown as rows the recipient can read in twenty seconds; the moment of transfer is one divider line and the apricot ring moving from one avatar to the next. Nothing on these screens is new chrome: the same box, the same line, the same ring.

1Ana offers

Ana holds the seat and is leaving for the day. "Hand off" sits in the top bar only for the driver; pressing it opens one notice in the stream: who, and one line of why. The people are rows with presence, not a picker. The accent sits on the Offer button, so the send arrow steps back.
