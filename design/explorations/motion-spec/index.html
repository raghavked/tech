How Fold moves

Five motions, three durations, three easings. Motion in Fold tells you that something changed and where; it never decorates. Every demo on this page is CSS only, and every one of them collapses to its end state under prefers-reduced-motion.

0Rules

What the whole system fits in.

  1. Nothing moves unless it changed. No idle motion anywhere except one dot, and that dot means a process is alive.
  2. Only opacity and transform, plus one measured width. Never colour alone, never blur, never scale above 1. The drawer and the notice slot are the only things that change size.
  3. Three durations: 120, 200, 320 ms. Micro, appear, move. Nothing on screen lasts longer than 320 ms except the pulse. Staggers are 36 ms and stop after the eighth sibling.
  4. Arriving decelerates, leaving accelerates, moving does both. Leaving is always shorter than arriving: the thing you asked to close should be gone before you look for it.
  5. The rest state is the end state. Hidden starts live in keyframes with fill: backwards. Setting animation: none is the complete reduced-motion fallback.

7Reduced motion

Because every element rests in its end state and keeps its start in a keyframe, the fallback is three lines of CSS, two of which already live in tokens.css. Nothing on this page needs a second set of styles to be correct without motion.

@media (prefers-reduced-motion: reduce) {
  /* tokens.css */
  * { transition: none !important; animation: none !important; }
  /* the thinking dot has no end state: hide it */
  .caret { opacity: 0; }
  /* the pulse rests solid */
  .status.running::before { opacity: 1; }
}

Motion is a sentence, not a flourish: this changed, it is here now.

Carry into the product: the three durations and three easings as the only motion tokens; the rest-state-is-end-state rule for every component; the pulse as the single idle motion. Anything that wants a fourth duration is probably decoration.
