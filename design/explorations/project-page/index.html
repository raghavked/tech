Project page

A project is where a team's sessions live together: Northwind › Payments › Billing page. The page follows claude.ai Projects: a direction field where the instructions would be, the sessions as plain rows with a status word, and team memory beneath. Nothing on it is a card except the two quiet notices, a contention and a memory conflict, and both are drawn in the crease colour rather than a new one.

Direction where instructions goclaude.ai puts a project's instructions at the top; Fold's equivalent is the direction field. What stands is one serif line beneath it with who set it and how far it reaches.
Status is a wordNeeds approval, Running, Blocked, Done: a dot and a word on the right of each row, the second line saying what the agent is doing in the agent's own grammar.
Conflicts are not alarmsA contention and a memory conflict are the only boxed things. Both use the apricot hairline, neither has a primary button, and both carry a status line so the reader knows who acts.
