Contrast audit, light and dark

Every text and background pair that tokens.css actually produces, with its WCAG contrast ratio computed on this page from the hex values. Text is held to 4.5:1, dots and boundaries to 3:1. A failing row carries its proposed replacement and the ratio that replacement would reach. Tonal pairs that carry no meaning are listed and marked exempt rather than left out.

Light

Paper canvas #FAF8F4 with Dress Blues ink. The tertiary tier and the amber dot are the problems.

Dark

#1F2430 canvas with warm off-white ink and Apricot as the accent. One real failure: the tertiary tier.

The tertiary tier, before and after

The one change people will see. Each strip is painted in its own palette regardless of the page theme, so the four read true side by side.

Changes to tokens.css

Four values move, one rule is added, and a high-contrast block gives the hairlines a real edge only for people who asked for one.

:root {
  --fg-2: #6B7080 #616676;   /* 5.39 on bg, 4.69 on bg-3: pills, chips and the segmented control pass */
  --fg-3: #9A9EA9 #6E727C;   /* 4.54 on bg: timestamps, roles, dividers pass on the canvas */
  --warn: #B9792E #AD6F2A;   /* 3.38 on bg-3: the amber dot passes on the active row */
  --info: #6B7080 #616676;   /* follows fg-2 */
}
/* dark, both the media block and [data-theme="dark"] */
  --fg-3: #7C8290 #9298A6;   /* 5.37 on bg, 4.83 on bg-2 */

/* rule: tertiary text lives on the canvas. on bg-2 and bg-3 the 12px labels use fg-2. */
.sidebar .section, .agent .foot, .agent:hover .foot { color: var(--fg-2); }

/* people who ask for more contrast get a real boundary on the composer and the notice */
@media (prefers-contrast: more) {
  :root { --line: rgba(42, 50, 68, 0.45); --highlight: #A87E55; }
  :root[data-theme="dark"], :root:not([data-theme="light"]) { --line: rgba(236, 232, 225, 0.40); }
}

Exemptions and what stays

Hairlines stay at 10%. Row dividers and the crease are decorative, and WCAG 1.4.11 does not apply to them. The composer boundary is the one that technically fails: its fill, placeholder and send arrow identify the field, and the high-contrast block above answers the strict reading.

The Apricot border carries a word. The contention notice and the driver ring sit at 1.56:1 on paper. Both are redundant with text ("contention", "driver"), which is why they are exempt and why that text must never be removed.

Status dots are never the only signal. They sit next to the status word everywhere, so 3:1 is the target and the only amber failure is on the active sidebar row.

The tiers compress a little. Light fg-3 moves from 60% to 45% lightness. The specimen shows it still reads as quieter than fg-2 because it is also smaller; that is the trade accepted here.
