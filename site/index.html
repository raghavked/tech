Henosis is the shared, living session where a team and its agents work on one piece. Anyone can drop in, steer, rate the plan, and hand the baton on. Your agents become members of the team, not tools beside it.

The session

A session everyone can drop into.

Every agent run is a hash-chained log that any teammate can join from the web, Slack, a phone or the terminal. The driver holds the baton; everyone else steers, constrains, asks for a brief, or forks a branch and unites it back.

Join mid-flight

Open a colleague's session at turn 40 with a handoff brief that says where it stands and what it needs.

Crews and the rail

The rail shows every agent, what it is on, whether it works solo or in a crew, and with whom. Claims and contentions surface before two agents touch one file.

Groups and chats

Mention an agent in a team chat and it answers from its session. Keep what it said for the whole team's memory, attributed to the engineer who ran it.

The council

A team's models deliberating.

Convene a council from any group: each member's model answers alone, then they discuss, a chair synthesises, and the synthesis becomes a plan the team rates. Managers instruct one model in private; every word is in the log, with dissent recorded.

Plan first

Plan, rate, then ship.

Nothing irreversible runs on a whim. Agents propose a plan with a token budget; the team rates it; a release gate asks for a minimum rating and an average before code reaches the consumers. Token usage is measured per person, per agent and per turn, and a manager's view shows it.

Ratings, not clicks

An approval is a rating from 1 to 5 with a note. An unrated approve is a voice, not a vote. The rule is per project.

Open the app

Run it in a minute.

The web app talks to a Henosis server over a websocket. Start one locally with the scripted model (no API key needed) and open the app; or point the hosted app at your own server.

pnpm install && pnpm build
HENOSIS_OFFLINE=1 pnpm serve        # the server on :7700 with the scripted model
pnpm --filter @henosis/web dev      # the app on http://localhost:5173

The hosted build of the app is at henosis-app-raghav14.vercel.app. It needs a server to join a session.
